# L'Aventure

Publier sous forme de BD en 9 cases dans la revues Jeux & Stratégies no 20.

Mécanisme de paragraphe à choix.\
L'idée est d'initier le joueur à ce type de mécanisme qui était alors assez récent en France.\
Introduit à l'époque par l'éditeur Galimard.

## Images

Les images sont encodées en Base64 et directement intégré dans l'histoire.

J'ai utilisé mon propre module autonome de conversion en base 64.

## Version stand alone basique

1ère adaptation faite "telle quelle". Un peu à l'arrache avec mes connaissance HTML, CSS et JavaScript.

Tout faire sois-même est fastidieux. D'où la bascule dans Twine pour les récits plus complexes.

## Version Twine

Adaptation dans Twine et Harlowe.
