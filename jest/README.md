# Jeux et Stratégies

Ancienne revue dans laquelle furent publiés plusieurs jeux solo.
Notamment des histoires à paragraphes (ou passage en terminologie Twine).

Je publie ici des adaptations au format Web.
Soit en pure HTML, soit via Twine. J'ai par ailleurs fait le choix de Harlowe.

La nomenclature ci-dessous est par numéro.
Quand c'est sous forme de lien, c'est que j'ai commencé l'adaptation et qu'elle est disponible.
* Basique, reprend simplement le formalisme de passage.
* Avec fonctionnalités, selon le cas, tirage des dés voir plus.
